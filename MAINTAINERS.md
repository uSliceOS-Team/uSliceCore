# Maintainers

This file identifies the people currently responsible for maintaining µSliceCore.

## Active maintainer

* [Vladislav Churilov](https://github.com/churil0wladislav) — project direction, API decisions, pull-request review, release preparation, and repository administration.

µSliceCore currently has one active maintainer. Membership in the uSliceOS-Team organization does not by itself indicate active maintainership.

The organization is intended to host a broader ecosystem of related components. This file applies specifically to the `uSliceCore` repository.

## Responsibilities

Maintainers are responsible for:

* reviewing and merging pull requests;
* defining supported public behavior;
* keeping tests and documentation aligned with that behavior;
* triaging reported defects and portability problems;
* preparing releases and maintaining release branches;
* avoiding unsupported safety, timing, or compliance claims.

## Becoming a maintainer

Maintainer status may be offered after sustained, technically sound contributions and demonstrated familiarity with the project’s design constraints.

Questions and proposals should be raised through GitHub Issues or Discussions rather than sent to maintainers privately.
